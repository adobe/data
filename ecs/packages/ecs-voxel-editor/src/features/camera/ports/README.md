# ports

Blender's view navigation, from the pointer, wheel and keys on the scene's canvas, as runs of the camera's systems.

| Input | Does |
|---|---|
| Middle drag, or Alt and left drag | Orbit |
| … with Shift | Pan |
| … with Ctrl | Zoom |
| Two-finger trackpad scroll | Orbit; with Shift, pan; with Ctrl, zoom |
| Pinch, or a mouse's wheel | Zoom |
| Numpad 1, 3, 7 | Front, right, top view; with Ctrl, back, left, bottom |
| Numpad 2, 4, 6, 8 | Orbit by 15° |
| W, S | Pitch the view up, down, smoothly while held |
| A, D | Turn the view left, right about the world's up, keeping it level, smoothly while held |
| N | Return to the starting view, framed |
| Home, numpad period | Frame the world |

The keys are read at each move, so pressing or releasing one mid-drag changes what the drag does from then on.
