# view

The file menu: `fileView` fills `menu-button.file` within the app's root with what can be done with documents, each
enabled as the library allows, and does what's chosen: a new document; a new model, asked for by name and size in the
page's `<form-dialog>`; choosing or reconnecting the library folder; and saving, asking for a path where the document
has none, and for Save as and Save standalone, with each model's thumbnail.
