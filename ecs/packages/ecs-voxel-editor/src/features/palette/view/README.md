# view

The palette: `paletteView` finds `<palette-panel>` within the app's root and writes its sections as what they show
changes:

- **In this document:** the materials its voxels use and the models its instances place;
- **Favorites:** the user's, materials, models and library files alike;
- **Materials** and **Models:** every one the document has, a model's thumbnail drawn from how it looks;
- **Library:** the library folder's files, by folder, with their saved thumbnails;

each kept to what the filter shows. Picking a library file brings its model into the document, referenced, to place
instances of; double-clicking a model edits it alone; a file's Open button opens it as the document.
