# ports

Selecting faces with the pointer on the scene's canvas, as runs of the selection's systems, each at the pointer's point
of the view.

The keys shape a drag whenever they're held: pressing or releasing one mid-drag changes it at once, and the
keys held as it's let go decide what it selects.

| Input | Does |
|---|---|
| Click | Toggle the face under the pointer |
| Drag | Select, or deselect, as the first face became, every face passed over |
| Shift during a drag | … a straight line of faces in the first face's plane |
| Ctrl or ⌘ during a drag | … a rectangle of faces in the first face's plane |
| Double-click | Select, or deselect, every face connected to the one under the pointer |
| Escape, Alt+A | Deselect every face |
