# view

Thumbnails of models: `thumbnailsView` gathers how each model looks, `modelLooks`, its voxels and its instances' in its
own voxels, in their materials' colors, as voxels, instances or models come or go. `drawThumbnail` draws one on a 2D
canvas as an isometric view turned to any angle, which the palette turns as the pointer rests on it, and
`thumbnailUrl` makes one a PNG, which saving keeps in the model's file.
