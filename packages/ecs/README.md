# @adobe/ecs

A data-oriented entity component system. Systems run on the main thread, on worker threads, as WASM kernels or on the GPU.

See the [guide](https://github.com/adobe/data/blob/main/packages/ecs/src/guide/guide.md) for how to use it. The
package ships its sources, so the guide is also at `src/guide/guide.md`.
